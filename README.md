# Website Liên Chi hội Sinh viên KTX 135 Trần Hưng Đạo

## Trang
- `index.html` — Trang chủ
- `departments.html` — Về chúng tôi / Giới thiệu các ban
- `programs.html` — Chương trình & hoạt động

## File giao diện
- `style.css` — màu sắc, bố cục, responsive
- `script.js` — menu mobile, nút lên đầu trang
- `assets/images/` — ảnh và logo

## Font chữ
Website sử dụng `UTF-8` và font hệ thống (`Segoe UI`, `Arial`, `Tahoma`, `sans-serif`) để hiển thị tiếng Việt ổn định trên GitHub Pages mà không phụ thuộc font ngoài.

## Cách cập nhật GitHub Pages
1. Giải nén file ZIP.
2. Trong repo đang chạy GitHub Pages, upload **toàn bộ file và thư mục bên trong** vào root.
3. Nếu GitHub hỏi file trùng tên, commit bản mới để thay thế.
4. Giữ nguyên cấu trúc thư mục `assets/images/`.
5. Chờ GitHub Pages build lại 1–3 phút và refresh trang.
